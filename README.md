# power-bi-dashboard
An Interactive Rural Employment & Expenditure Analytics Dashboard
- Turning Government Data into Meaningful Insights
-Project Overview
    MGNREGA Insight360 is an interactive data analytics project designed to explore and evaluate employment generation,            household participation, women's workforce participation, and expenditure patterns under the Mahatma Gandhi National Rural     Employment Guarantee Act (MGNREGA).
    The project aims to transform government data into meaningful insights through interactive visualizations, enabling users      to explore rural employment trends, assess program performance, and understand expenditure distribution across different       dimensions.
  
-Project Objectives
    Analyze employment generation and person-day trends.
    Evaluate household participation and completion of 100 days of wage employment.
    Examine women's participation in rural employment.
    Analyze expenditure patterns across different categories.
    Monitor wage payment performance and payment timelines.
    Identify trends and variations across financial years.
  
-Key Dashboard Features
    Employment Analysis: Explore total person-days and employment generation trends.
    Household Performance: Analyze households completing 100 days of wage employment.
    Women Participation: Track women's contribution to employment generation.
    Expenditure Analysis: Examine expenditure distribution across agriculture, allied works and natural resource management.
    Payment Performance: Evaluate the percentage of payments generated within 15 days.
    Time-Based Analysis: Explore performance using financial year, month and date-level drill-down.
    Interactive Exploration: Use slicers, filters and drill-down features to investigate different aspects of the dataset.

-Tools & Technologies

    Data Visualization – Interactive Charts and Reports

-Analytical Approach

-Business Value
    This dashboard provides an analytical perspective on rural employment program performance. It helps users explore            employment trends, household participation, women's involvement, expenditure allocation and payment efficiency.
